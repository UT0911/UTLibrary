# UTLibrary
競技プログラミングでよく使うものや書くのが手間になるものを関数でまとめています
変数の型などは固定です

## BFS
`BFS.cpp`

盤面が $S$ で表されている$H \times W$ のグリッドの $(sh,sw)$ からの距離を求めます

グリッドの左上は $(0,0)$ です

### 入力
* 盤面の縦の長さを表すint型変数 $H$
* 盤面の横の長さを表すint型変数 $W$
* 盤面の状態(`#`が壁)を表す文字列配列 $S$
* 開始地点が上から何番目かを表すint型変数 $sh$
* 開始地点が左から何番目かを表すint型変数 $sw$

### 出力(返り値)
* $(sh,sw)$ からの距離を記録した$H \times W$ の二次元配列visited(返り値)
